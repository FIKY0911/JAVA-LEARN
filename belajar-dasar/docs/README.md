# Java Dasar - Belajar Dari Nol

Kumpulan materi belajar Java dasar, diorganisir berdasarkan topik.
Setiap folder berisi file `.java` yang bisa langsung dijalankan dan satu file `.md` penjelasan.

## Struktur

| # | Topik | File |
|---|-------|------|
| 01 | Hello World & Text Displaying | HelloWorld.java, TextDisplaying.java |
| 02 | Variabel & Deklarasi | Variable.java |
| 03 | Tipe Data Primitive | Boolean, TipeDataNumber, TipeDataChar, TipeDataString, KonversiNumber, KataKunciFinal |
| 04 | Tipe Data Non-Primitive | TipeData.java |
| 05 | Operator, Operan & Ekspresi | OperatorAritmatika, OperatorPerbandingan, OperatorLogika, OperatorTernary, EkspresiDanOperan |
| 06 | String | StringMethod.java |
| 07 | Kondisional | IfElse.java, SwitchCase.java |
| 08 | Perulangan | ForLoop, WhileLoop, DoWhileLoop |
| 09 | Array | Array.java |
| 10 | Method & Class Method | Method.java, ClassMethod.java |

## Cara Menjalankan

```bash
cd <folder>
javac <NamaFile>.java
java <NamaFile>
```

Contoh:
```bash
cd 01-hello-world
javac TextDisplaying.java
java TextDisplaying
```
