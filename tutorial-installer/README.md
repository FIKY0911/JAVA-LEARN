## 🎯 Ringkasan Isi Dokumentasi

1. **Instalasi Java (JDK 21 LTS)**
   - Windows (GUI Installer & `winget`)
   - Linux (APT/Ubuntu, DNF/Fedora, Pacman/Arch, & Tarball `.tar.gz`)
   - Konfigurasi `JAVA_HOME` & `PATH` Environment Variables

2. **IntelliJ IDEA Ultimate (Lisensi Student)**
   - Cara Pengajuan Lisensi Gratis JetBrains Educational Pack
   - Instalasi di Windows (JetBrains Toolbox & Installer `.exe`)
   - Instalasi di Linux (Snap, Toolbox, & Tarball `/opt/`)
   - Aktivasi Lisensi & Setup JDK

3. **Visual Studio Code (VS Code) + Java Extensions**
   - Instalasi VS Code di Windows & Linux
   - Instalasi Paket Ekstensi Wajib (*Extension Pack for Java*) & Ekstensi Pendukung (*Spring Boot*, *Lombok*, *Gradle*)
   - Konfigurasi `settings.json` untuk Java Runtime Path

4. **Pengujian Proyek Pertama & Troubleshooting**
   - Uji coba skrip "Hello World"
   - Solusi untuk masalah umum (`Command Not Found`, `JAVA_HOME is not set`, Lisensi Student, dll.)
